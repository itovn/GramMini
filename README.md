# GramMini

Telegram cho iOS 5 / 6 (ứng dụng không chính thức).

Đây là nơi đặt **bản phát hành** (tệp `.deb` trong mục Releases) để app tự cập nhật.

- Cài và cập nhật qua Cydia, nguồn: **https://repo.caominh.net/**
  (nguồn cũ https://itovn.github.io/GramMini/cydia/ vẫn chạy)
- Trang giới thiệu: https://repo.caominh.net/grammini/
- Hỏi đáp, báo lỗi: nhóm Telegram **@tivikit** (t.me/tivikit)
