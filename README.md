# Trang GramMini (nhánh gh-pages của itovn/GramMini)

Trang giới thiệu và nguồn Cydia của [GramMini](https://github.com/itovn/GramMini) — Telegram cho iPhone / iPad iOS 5 / iOS 6
đã jailbreak.

- Trang: https://itovn.github.io/GramMini/
- Nguồn Cydia: `https://itovn.github.io/GramMini/cydia/` — tạo bằng `tools/update-cydia-repo.sh` của repo GramMini.

Trang viết cho Safari iOS 5 / 6 (không biến CSS, flex, grid; dải màu có tiền tố `-webkit-`).
