# GramMini.github.io

Trang giới thiệu và nguồn Cydia của [GramMini](https://github.com/itovn/GramMini) — Telegram cho iPhone / iPad iOS 5 / iOS 6
đã jailbreak.

- Trang: https://GramMini.github.io/
- Nguồn Cydia: `https://GramMini.github.io/cydia/` — tạo bằng `tools/update-cydia-repo.sh` của repo GramMini.

Trang viết cho Safari iOS 5 / 6 (không biến CSS, flex, grid; dải màu có tiền tố `-webkit-`).
